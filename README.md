# AI Resume Job Matcher

## 🚀 Features
- Upload Resume (PDF)
- Parse Resume using NLP
- Match with Job Description
- Displays Match Percentage
- Shows Matched & Missing Skills

## 🧠 How It Works
- Extracts text from resume PDF
- Parses job description
- Identifies required skills dynamically
- Calculates match score based on skill overlap

## 🛠 Tech Stack
- Frontend: React (Vite)
- Backend: Node.js, Express
- Libraries: pdf-parse, multer

## ▶️ Run Project

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm run dev

## 🌐 URLs
Frontend: http://localhost:5173  
Backend: http://localhost:5000
